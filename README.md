# CompanyEmployees API
RESTful Web API для управления сотрудниками и компаниями.

# База проекта
Этот проект является практической реализацией и развитием концепций, описанных в книге "Ultimate ASP.NET Core Web API" от команды Code Maze.
В процессе работы над проектом были изучены и применены на практике паттерны проектирования, механизмы безопасности и оптимизации производительности, рекомендованные авторами для создания коммерческих веб-служб на .NET.

# Архитектура и паттерны
* Проект спроектирован с упором на слабую связанность компонентов (Loose Coupling), тестируемость и масштабируемость:
* Onion Architecture (Луковая архитектура): 
* Четкое разделение на слои (Domain, Services, Infrastructure, Presentation, API). 
* Бизнес-логика полностью изолирована от внешних фреймворков и баз данных.
* Repository Pattern & Generic Repository: Использование паттерна "Репозиторий" для абстракции работы с базой данных (Entity Framework Core) и оптимизации запросов к БД.
* CQRS (MediatR: Разделение операций чтения и записи для повышения производительности и читаемости кода.

# Реализованный функционал и технологии
В ходе разработки были успешно интегрированы следующие механизмы:
* База данных: EF Core (Code First), миграции, связь один-ко-многим/многие-ко-многим.
* Валидация и DTO: Разделение доменных моделей и моделей передачи данных (DTO), валидация входящих запросов.
* Глобальная обработка ошибок: Кастомный Middleware для централизованной обработки исключений и логирования (NLog / Serilog).
* Фильтрация, сортировка и пагинация: Реализован гибкий механизм поиска, постраничного вывода и сортировки данных на стороне базы данных.
* HATEOAS: Поддержка самодокументируемого API (передача ссылок на связанные действия в ответах сервера).
* Кэширование и Rate Limiting: Защита API от перегрузок и оптимизация повторных запросов (механизмы маркерных ведер, кэширование ответов).
* Безопасность (Identity & JWT): Аутентификация на базе ASP.NET Core Identity, генерация и валидация JWT-токенов, поддержка Refresh Tokens.
* Версионирование API: Поддержка работы с несколькими версиями API одновременно (Query string / Header versioning).
